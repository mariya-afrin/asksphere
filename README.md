# AskSphere

**Ask. Share. Learn Together.**

A community question-and-answer platform. Users can ask questions on any topic, post answers, vote, comment, bookmark, and moderate reports through an admin dashboard.

## Tech Stack

- **Framework:** Nuxt 4 (Vue 3, TypeScript)
- **Styling:** Tailwind CSS
- **Server:** Nitro (built into Nuxt)
- **Database:** MongoDB Atlas + Mongoose
- **Auth:** Session-based with bcrypt-hashed passwords
- **Validation:** Zod
- **Icons:** lucide-vue-next
- **Tests:** Vitest

## Prerequisites

- Node.js 20 or 22 LTS (Node 24 works too)
- npm 10+
- A MongoDB Atlas account (free tier is fine)
